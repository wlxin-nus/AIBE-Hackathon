# Compact design proposal

The challenge is known: People-Centred Low-Carbon Portfolios. Design Common Climate, an opt-in workplace thermal preference system. Codex handles implementation; your output is a visual concept for user approval. Use the supplied frontend-design guidance. No tools, no file writes.

Output ONLY a complete standalone HTML document with inline CSS and SVG. Maximum 2200 words, no markdown fences, no JavaScript or remote assets. No code comments. At a 1440x900 viewport show one polished board: a large building dashboard (about 1050px wide) and a narrow mobile preview beside it. English text only. Desktop app: light architectural palette, teal and muted coral, clean Segoe UI typography, a central abstract three-zone VAV canvas with two occupants and gentle presence halos, a short zone setpoint list, and compact evidence panel. Phone: alias, preferred temperature 24.5 C, acceptable range 23–26 C, location selection, export and leave buttons. Make it visually memorable through the spatial canvas, not decorative metrics.

Essential labels: 'Design concept · illustrative data'; 'Manual position'; 'Presence, not measured temperature'; 'Simulated zone-air setpoint'; baseline 25 C is a demo assumption; 'Energy impact: not measured'. Show one conflicting preference and an operator-review state. Avoid claims of live indoor location, working Bluetooth, real HVAC control or measured carbon savings. Do not add a long explanation. This design is reviewed before integration; Codex is independently building a LAN functionality probe. The full product may later compare shared-space allocation across floors to connect to portfolio decisions.
