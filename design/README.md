# Common Climate design proposal

`comfort-concept.html` is a static proposal produced by Claude Code using `claude-opus-5-5` with explicitly requested `high` effort and the project-local `frontend-design` skill. The successful request completed on 31 October 2026 in 153.411 seconds. Codex saved the returned HTML and visually inspected it in Chrome.

Open `/concept` on the local prototype server, or open the HTML directly. The illustrated floor plan, occupants, comfort values and setpoints are examples for visual review. The buttons in this proposal are not connected to the functional experiment. Actual two-phone testing uses `prototype/` and the `/phone` route.

Review the spatial hierarchy, palette, participant halos, conflict explanation and phone layout before integrating the final interface. Do not interpret the proposal as verified positioning, HVAC control or energy savings.
